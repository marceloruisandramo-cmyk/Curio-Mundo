Gerador de Conteúdo do Curio Mundo

Esta ferramenta funciona 100% no seu navegador, sem banco de dados, sem login e sem servidores. Ela gera arquivos HTML semânticos prontos para serem salvos na pasta /artigos/ e publicados pelo Cloudflare Pages via GitHub.

Criar Novo Artigo com Gerador Automático Ver Modelo HTML em Branco (Template Puro)

Passo a Passo Para Adicionar Novos Artigos:

  1. Abra o Gerador de Novo Artigo;
  2. Preencha o título, categoria, subtítulo, resumo, conteúdo, curiosidade e fontes;
  3. O gerador criará automaticamente o slug limpo (ex: por-que-o-ceu-e-azul.html);
  4. Clique em "GERAR ARTIGO HTML";
  5. Clique em "Baixar Arquivo HTML" (o arquivo já é salvo com o nome exato);
  6. Mova o arquivo baixado para a pasta correspondente: artigos/<categoria>/;
  7. Adicione o artigo à lista do arquivo js/app.js (para a pesquisa do site);
  8. Atualize o arquivo sitemap.xml com a nova URL;
  9. Faça o commit e push no GitHub;
  10. O Cloudflare Pages detecta a alteração e atualiza o site instantaneamente!
